    UTF-8 CSV · 200KB / 최대 1,000행 · 첫 행은 열 이름

    정리 결과

    문자열 유지
    —결과 행
    —제거한 중복
    —정리한 셀

    샘플을 실행하면 정리된 표가 표시됩니다.

    CSV는 UTF-8 BOM을 포함합니다. 엑셀에서 직접 열면 앞자리 0 등이 자동 변환될 수 있으므로, 중요한 열은 텍스트로 가져오세요.

    업무표에서 진행 현황을 한눈에.

    분류·작업·상태 세 열을 읽어 상태별 건수와 업무 목록을 정리합니다.

    열 이름: 분류,작업,상태 · 상태: 완료 / 진행 / 대기

    실행하면 작업 현황과 인쇄용 보고서가 표시됩니다.

    PDF 저장은 브라우저의 인쇄 기능에서 선택합니다. 보고서 파일은 브라우저에서 만들어집니다.

    실제 업무에는 파일 크기, 원본 규칙, 실행 환경에 맞춘 설계가 필요합니다.
